## 📖 How to Use

1.  **Browse:** Navigate to the folder matching the service or node you're interested in.
2.  **Select:** Open any `.json` file.
3.  **Import:**
    *   **Option A:** Copy the JSON content and paste it directly into your n8n canvas (`Ctrl+V` or `Cmd+V`).
    *   **Option B:** Use the **Import from File** option in the n8n menu and select the JSON file.
4.  **Configure:** Update credentials and specific parameters (like Sheet IDs or URLs) within n8n.

## 🛠 Project Structure

These templates are intended as boilerplate starters. Always review the workflow structure and ensure you are using your own credentials. **Never share JSON files that contain private API keys or sensitive data.**
